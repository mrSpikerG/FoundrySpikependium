# Spikependium — Unearthed Arcana (RU)

Русскоязычные материалы D&D для **Foundry VTT 14** и **D&D 5e 6.x**, преимущественно по правилам 2024 года. Перевод UA: Koroz.

## Установка и обновление

В меню настройки Foundry открой **Дополнительные модули → Установить модуль** и вставь в **Manifest URL**:

```text
https://github.com/mrSpikerG/FoundrySpikependium/releases/latest/download/module.json
```

В мире включи **Spikependium**, **Babele** (2.8+) и **libWrapper**; выбери русский язык. Материалы находятся в компендиумах папки **Spikependium**.

Для обновления выйди из мира и нажми **Обновить** у модуля в меню настройки Foundry. Уже добавленные на листы персонажей записи автоматически не заменяются.

Перенос книг и автоматизация продолжаются; часть условий требует подтверждения игрока или Мастера. Некоторые материалы вне SRD нужно добавить из своей книги.
